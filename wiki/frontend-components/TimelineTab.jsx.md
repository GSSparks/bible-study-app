# frontend/src/components/TimelineTab.jsx

## Purpose

Placeholder tab within `CursusView` for a future Timeline feature. Displays a centered "Timeline coming soon." message. No data fetching or interaction.

## Props

| Prop | Type | Description |
|---|---|---|
| `isLoggedIn` | boolean | Passed through from `CursusView`; not currently used |

## State / key logic

None. Renders a single centered paragraph.

## Dependencies

None.

## Notes

- The tab appears with 50% opacity in the `CursusView` tab bar (`tab.soon = true`) to visually indicate it is not yet functional.
- When the Timeline feature is implemented, this file will be replaced with the full component.
